# Recharge Reminder

A simple Android app that reminds you to recharge your mobile line (Alfa, Touch or any carrier) before it expires, so you don't lose your number or your remaining balance.

## Features

- Add all your lines (yours, family members') with their expiry date.
- Color-coded countdown: green (fine), orange (recharge soon), red (expires today / expired).
- Reminder banners and phone notifications when a line is within your chosen number of days.
- **Add to calendar**: downloads a calendar event with alarms, so you get reminded even when the app is closed.
- **I recharged**: moves the expiry forward by the line's validity (30 days by default).
- Works offline and can be installed on the home screen. Data stays on your phone only.

## Install on Android

Every push to `main` builds the app on GitHub and publishes it on the
[latest release](../../releases/tag/latest).

1. On your Android phone, open the latest release page and download **RechargeReminder.apk**.
2. Open the file. If Android asks, allow installing apps from your browser or file manager.
3. Open **Recharge Reminder** and allow notifications.

New versions install over the old one and keep your saved lines.

## How reminders work

The app schedules Android notifications at 9:00 AM on your reminder day
(3 days before expiry by default) and at 9:00 AM on the expiry day. They
arrive even when the app is closed. After you recharge, tap **I recharged**
and the reminders move to the new expiry date.

## Project layout

- `www/`: the app itself (HTML, CSS, JavaScript).
- `android/`: the Android project, generated by [Capacitor](https://capacitorjs.com).
- `.github/workflows/android.yml`: builds the APK on GitHub.

## Develop

Requires Node 22, Java 21 and the Android SDK.

```sh
npm ci
npm run build:apk   # APK at android/app/build/outputs/apk/debug/app-debug.apk
```

To try the app in a browser, serve `www/` (`cd www && python3 -m http.server 8000`).
In a browser, reminders only show while the page is open, so use **Add to calendar** there.
